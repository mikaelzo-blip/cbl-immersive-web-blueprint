# 01 — Project Vision

## Positioning

Website CBL harus memosisikan perusahaan sebagai **technical execution partner** yang mampu memahami kebutuhan fasilitas, membaca sistem, melaksanakan pekerjaan, menguji, dan mendokumentasikan hasil.

Bukan sekadar "kontraktor serba bisa" dan bukan katalog layanan generik.

## Primary audience

- facility / engineering manager
- procurement
- project owner
- operations team
- calon partner/vendor
- orang non-teknis yang perlu memahami kemampuan CBL dengan cepat

## User should feel

Dalam 10–20 detik pertama:

1. perusahaan ini nyata
2. pekerjaannya teknis
3. mereka punya pengalaman lapangan
4. mereka mampu menjelaskan sistem dengan jelas
5. website ini tidak terasa seperti template

## Brand personality

- precise
- composed
- capable
- grounded
- technical
- understated confidence

Hindari tone bombastis seperti "industry-leading", "world class", atau klaim superior tanpa bukti.

## Core experience concept

**Technical systems become understandable through immersive visual explanation, then credible through real project documentation.**

3D membuka cerita. Foto lapangan menutup loop ke real-world execution.

## Success criteria

Website dianggap sukses bila:

- calon klien cepat memahami scope kemampuan
- portofolio terasa dipercaya karena berbasis dokumentasi nyata
- desain memiliki identitas visual khusus
- 3D membantu penjelasan, bukan menghambat
- mobile tetap nyaman
- contact/project inquiry jelas
- tidak ada marketing claim palsu

## Current capability themes

Prioritas storytelling:

1. mechanical / gearbox / conveyor
2. electrical & automation / control panel
3. pump & water system
4. HVAC
5. lighting / DMX
6. procurement / technical ecosystem

## Design north star

Bayangkan kombinasi:

- editorial annual report
- industrial product visualization
- architecture studio website
- engineering case-study presentation

Bukan kombinasi:

- SaaS landing page
- crypto interface
- startup template
- agency template yang dipenuhi hover gimmick
