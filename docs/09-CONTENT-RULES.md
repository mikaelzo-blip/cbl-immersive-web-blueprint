# 09 — Content Rules

## Principle

CBL website copy must be credible before it is impressive.

## Source hierarchy

Use content from:

1. verified company profile / legal documents
2. verified project documentation
3. confirmed service capability data
4. human-approved website copy

Do not treat old website marketing copy as automatically authoritative.

## Allowed copy style

- concrete
- concise
- technical but readable
- specific about process
- confident without exaggeration

Example:

> Pemeriksaan, penggantian komponen, alignment, pengujian, dan dokumentasi pekerjaan dilakukan sesuai kebutuhan sistem di lapangan.

## Avoid

- "solusi terbaik"
- "nomor satu"
- "world class"
- "leading provider"
- claims about savings/performance without evidence
- unsupported years/volume/client counts

## Project case study template

Prefer:

- project / scope title
- discipline
- context / need
- work performed
- testing/commissioning if documented
- result/handover wording only if supported
- real image captions

Do not expose confidential transaction or tender data simply to make the portfolio look detailed.

## Technical terminology

Keep manufacturer/model names exact when sourced.

Do not replace precise terms with vague marketing synonyms.

Where a general audience may not understand a term, explain it briefly rather than removing technical specificity.

## CTA language

Prefer practical CTA:

- Diskusikan proyek
- Konsultasikan kebutuhan teknis
- Lihat pekerjaan
- Lihat kapabilitas
- Hubungi CBL

Avoid startup language:

- Get started
- Unlock your potential
- Transform your business
