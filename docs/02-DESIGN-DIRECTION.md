# 02 — Design Direction

## Visual character

Target visual language:

**industrial + editorial + architectural + premium corporate**

The website should feel designed by humans with restraint.

## Typography

Typography should do heavy visual work.

Guidelines:

- strong display scale for hero
- body copy with comfortable line length
- clear contrast between narrative and metadata
- use uppercase micro-labels sparingly
- avoid excessive font-weight switching
- avoid decorative type tricks that reduce clarity

## Layout

Preferred:

- asymmetrical grids
- large quiet areas
- full-width project imagery where appropriate
- staggered editorial compositions
- horizontal rules/dividers
- technical indexes and registers
- sticky storytelling where it improves comprehension

Avoid:

- repeated 3-column card grids
- identical section templates
- centered heading + subtitle + cards repeated down the page

## Color

Direction:

- warm off-white / paper-like neutral
- deep navy / engineering blue-black
- restrained industrial orange/rust accent
- neutral steel/gray

Do not turn the palette into neon tech.

## Imagery

Priority order:

1. real CBL project photography
2. purpose-built 3D technical visualization
3. diagrams / annotated system graphics
4. carefully selected supporting imagery only if needed

Avoid generic stock workers wearing hard hats simply to fill a space.

## UI surfaces

Prefer flat editorial surfaces with border/rule hierarchy.

Rounded corners are allowed only when they support an object/image treatment. They should not become the default container language.

Shadows should be rare.

## Motion

Motion should feel mechanical and intentional:

- slow camera progression
- subtle object rotation
- precise reveal timing
- short hover shifts
- pinned/sticky transitions

Avoid bouncy spring motion unless there is a strong reason.

## Interaction rhythm

Page should alternate between:

- immersive technical visualization
- quiet editorial explanation
- real project evidence
- structured capability information

This rhythm prevents the experience from becoming either too static or too gimmicky.
