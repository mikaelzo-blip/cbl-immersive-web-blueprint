# Catatan Refinement

## Sumber

Konten portofolio disusun dari repository awal, dokumen analisis, dan arsip proyek yang diberikan pemilik perusahaan.

## Proyek unggulan

1. Penggantian Soft Starter pada Sistem Lift dan Pompa
2. Penyetelan Roll dan Komponen Penahan Sistem Conveyor
3. Instalasi Sistem Pencahayaan Area Rekreasi
4. Perbaikan Sistem AC VRF pada Gedung Operasional
5. Penggantian Instalasi AC Split Duct
6. Pemasangan Panel View HMI untuk Monitoring Peralatan

## Privasi

Source code publik tidak memuat nomor PO/SPK, nilai kontrak, nama klien, nama penandatangan, tanda tangan, stempel, nomor rekening, atau data perpajakan.

## Validasi sebelum go-live

- Konfirmasi izin penggunaan foto.
- Konfirmasi nomor WhatsApp, alamat, jam layanan, dan domain.
- Ganti email Gmail dengan email domain setelah aktif.
- Jalankan `npm ci`, `npm run typecheck`, `npm run lint`, dan `npm run build`.


## Penambahan portofolio tahap 2

Dua belas proyek tambahan telah dimasukkan ke halaman portofolio sehingga total menjadi 18 proyek. Proyek tambahan meliputi DC drive, pompa submersible, kompresor udara, shaft dan gearbox, inverter, conveyor, lighting underwater, penerangan kolam, bearing roda, gearbox industri, pompa booster, dan UPS.

Seluruh judul menggunakan penyebutan publik yang digeneralisasi. Nomor PO/SPK, nilai transaksi, identitas klien, dan data sensitif tidak dirender pada website. Enam proyek awal tetap menjadi proyek unggulan homepage, sedangkan proyek tambahan tersedia pada halaman daftar proyek dan filter kategori.
